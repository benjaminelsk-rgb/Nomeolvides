# Nomeolvides 🌳

App para guardar ideas (de negocios, canciones, clases, viajes… lo que sea) y no olvidarte de ninguna.

- Escribí, grabá notas de voz o tarareá melodías.
- Ordená tus ideas en **ramas** y **ramitas**.
- Seguí su estado: semilla → brote → flor.
- Recordatorios como alarmas, y se pueden sumar al calendario del celular.
- Funciona sin internet y se instala en el iPhone y en la compu.

Tus ideas se guardan en tu dispositivo (no en este repositorio).
